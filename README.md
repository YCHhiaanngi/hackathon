# hackathon

## 听见颜色（前端）

面向视障用户的实时衣物颜色识别与语音对准引导。桌面端网页：用户把衣物举到电脑摄像头前，系统语音提示调整位置，稳定后自动识别并播报颜色。

- 接口契约（前后端共享）：[docs/api-contract.md](docs/api-contract.md)
- 前端交接（配置、文件职责、已验证/未验证项）：[docs/frontend-handoff.md](docs/frontend-handoff.md)
- 验收清单：[ACCEPTANCE.md](ACCEPTANCE.md)

### 快速开始

```bash
npm install
npm run dev
```

默认演示模式（Mock），无需后端即可体验完整流程；接入真实服务见交接文档。
