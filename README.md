# 听见颜色

> 让看不见颜色的人，也能自己挑选今天穿的衣服。

**线上体验：<https://ychhiaanngi.github.io/hackathon/>**（桌面端 Chrome / Edge，需摄像头）

## 初衷与背景

对视障朋友来说，"这件衣服是什么颜色"是一个每天都要面对、却很难独立回答的问题。颜色无法触摸，也难以描述——买衣服、搭配穿着、区分深浅衣物，往往只能求助他人。

现有工具大多要求用户"拍一张照片再识别"：对准、构图、按快门，每一步都依赖视觉反馈，恰恰把目标用户挡在门外。

**听见颜色**想换一种方式：用户只需把衣物举到电脑摄像头前，剩下的交给系统——

- 找不到衣物？系统会**语音告诉你**怎么移动；
- 位置偏了？系统会说"请把衣物向你的左手方向移动一点"；
- 放稳了？系统**自动识别并播报**颜色，全程不用看屏幕、不用按快门。

我们相信：好的无障碍设计，不是让视障用户去适应明眼人的操作方式，而是让产品主动适应他们。

## 实现的功能

- **实时语音对准引导**：持续预览 + 自动抽帧（500ms），根据目标位置给出简短、单一方向的语音指引；左右方向以用户身体为参照，首次使用通过两步校准确认方向映射
- **自动识别与播报**：目标稳定后自动触发颜色分析并播报，无需确认点击；颜色不变不重复打扰，更换衣物后自动识别新颜色
- **真实本地视觉**：固定背景差分 + 连通区域定位目标区域，掩膜内真实像素做颜色分类，支持红/橙/黄/绿/青/蓝/紫/粉/棕/黑/白/灰中文颜色名与次要颜色；全部计算在浏览器内完成，**不上传任何画面、无需网络与密钥**
- **诚实的能力边界**：不做语义猜测——物品名称不确定时播报"目标区域"，图案未实现就返回 unknown，不伪造准确率数字
- **无障碍设计**：应用语音 / 读屏模式双通道切换，全键盘操作（空格 = 开始/暂停/继续），大字体高对比界面，动态状态走 aria-live
- **防错与健壮性**：结果时效校验（过期不播报）、防重复防跳变、暂停/停止即释放资源、摄像头异常分类提示
- **演示模式**：内置 Mock 场景脚本（明确标注"模拟引导"），无摄像头也能体验完整流程与路演演示

## 使用条件与限制

摄像头固定、背景简洁、光照均匀时效果可靠；复杂背景与剧烈光照变化下定位为受限能力（当前为固定背景辅助模式，非语义级衣物识别）。详见 [验收记录](docs/acceptance.md)。

## 快速启动

```bash
npm install
npm run dev          # 打开 http://localhost:5173/
```

```bash
npm run test:local   # 本地视觉算法自检（30 项合成图用例）
npm run build        # 类型检查 + 构建到 dist/
```

详细操作（背景校准、方向校准、三件衣物验证、发布流程、故障排查）见 [操作手册](docs/runbook.md)。

## 技术栈与部署

Vite + React 19 + TypeScript（strict），纯静态站点，GitHub Actions 自动部署到 GitHub Pages（推送 `master` 分支即发布）。定位与颜色识别均在前端本地完成，线上基础流程不依赖任何后端。

## 未来前景

- **语义级识别**：接入浏览器端轻量模型（如 ONNX Runtime Web / Transformers.js）识别衣物类型、图案（条纹/格纹）与材质描述，从"目标区域的颜色"升级为"一件蓝色条纹的衬衫"
- **多场景适应**：自适应背景建模 + 光照补偿，摆脱固定背景限制，支持手持手机移动取景（移动端 PWA）
- **更完整的穿搭辅助**：两件衣物颜色搭配建议、衣物收纳标记、与语音助手联动
- **个性化**：用户自定义颜色叫法（"藏青"还是"深蓝"）、语速与提示详细程度
- **远程增强模式**：契约已预留 HTTP 接口（[docs/api-contract.md](docs/api-contract.md)），可按需接入云端视觉模型增强描述能力，密钥只在服务端
