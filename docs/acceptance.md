# 验收记录 · 听见颜色

> 分支：`feature/local-vision-integration`。记录时间：2026-10-11。
> 合成图、浏览器虚拟摄像头、真实摄像头三类验证分别记录，互不冒充。

## 识别方法（主流程）

**浏览器本地「固定背景辅助模式」**：开始时会话内采集约 3 秒基准背景（冻结，不随时间吸收目标）→ 每帧差分 + 形态学去噪 + 连通区域提取前景候选 → 区域位置驱动引导 → 稳定后在掩膜内对真实像素做颜色分类。这是真实图像处理，但**不是语义上的衣物识别**：`objectName` 返回 null，播报口径为“目标区域”。未实现图案识别，`pattern` 恒为 `unknown`。

## 受限制的场景（如实声明）

- **固定背景辅助模式的前提**：摄像头固定、背景简洁、光照均匀。身体大幅移动、他人入镜、背景与衣物同色会降低可靠性。
- 候选区域可能包含手或身体移动（前景算法无法区分语义），多候选时会提示“一次只展示一件”，不会自行猜测。
- 复杂/杂乱背景、光照剧烈变化环境下**未完成**衣物级定位；语义物品名称（上衣/裤子）与图案（条纹/格纹）识别**未实现**。
