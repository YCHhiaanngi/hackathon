## 6. 页面操作入口

底部控制区最左侧的蓝色 **“开始识别”** 按钮（Tab 键可聚焦，回车触发）。

## 7. 摄像头权限

- 首次点击“开始识别”，浏览器地址栏左侧弹出权限请求 → 选 **允许**。
- 页面顶部状态会从“等待摄像头授权”变为“已开启”。
- **误点了拒绝**：点击地址栏左侧的锁形/摄像头图标 → 将摄像头改为“允许”→ 点“停止”再点“开始识别”。
- 页面会明确区分：权限被拒绝 / 没有设备 / 设备被占用 / 尚未就绪。

## 8. 背景校准与方向校准

**背景校准（本地模式自动进行）：**
1. 点击“开始识别”后，语音提示“请先把手中的衣物移出画面……”。
2. 保持坐姿和摄像头不动，把衣物移出画面，等待约 3 秒（右侧面板有进度条）。
3. 听到“背景采集完成”即校准完成。摄像头被移动或光照剧变时会自动提示重新采集。

**方向校准（首次找到稳定目标后自动进行）：**
1. 听到“请把衣物向你的右手方向轻轻移动一点”→ 把衣物向**自己的右手**方向轻移。
2. 听到“请把衣物向上移动一点”→ 向上轻移。
3. 听到“方向校准完成”后，后续左右/上下提示才以你的身体为参照。
4. 移动不明显或目标丢失时不会宣布成功，会稍后自动重试。

## 9. 如何判断已进入真实模式

- 顶部徽章显示 **“真实模式（本地图像处理）”**（绿色）。
- 页面**没有** Mock 场景下拉框，视频上没有“模拟引导”黄色角标。
- 识别结果的文字以“目标区域的主要颜色是……”开头（本地模式不做语义识别，不编造“上衣”）。

## 10. 用三件不同颜色的衣物验证

1. 准备颜色差异大的三件衣物（如红、蓝、黑），背景尽量简洁（纯色墙面/桌面）。
2. 开始识别并完成背景校准。
3. 举起第 1 件：按语音调整位置 → 听到“可以了，请保持不动” → 等待自动播报颜色。
4. 移开第 1 件（听到目标丢失提示、结果标注“上次结果”），换第 2 件，重复。
5. 三件轮流验证；“最近结果”列表应依次出现三条不同颜色的记录。
6. 对比验证：把衣物移出画面应提示“还没有找到衣物”；两件同时入镜应提示“请一次只展示一件衣物”。

## 11. 停止与重新启动

- **暂停**：保留画面，停止分析和播报；点“继续”恢复。
- **停止**：释放摄像头、清空语音；再次点“开始识别”会重新开始（新会话 + 重新采集背景）。
- 切换到其他标签页会自动暂停分析；回来后点“继续”。

## 12. 构建并发布到 GitHub Pages

```bash
git checkout master          # 或 main，以仓库发布分支为准
git merge --no-ff feature/local-vision-integration
git push origin master
```

推送后 GitHub Actions（`.github/workflows/deploy.yml`）自动执行 `npm ci` → `npm run build` → 发布 `dist/` 到 Pages。在仓库 Settings → Pages 查看地址（通常为 `https://<用户名>.github.io/hackathon/`）。

线上为纯静态站点，本地视觉在浏览器内运行，**线上基础流程不依赖任何 localhost 或后端**。

## 13. 后端部署（当前不需要）

主流程完全在浏览器本地完成，**没有需要部署的后端**。
如未来启用远程模式（`VITE_API_MODE=http`）：

1. 后端实现 `docs/api-contract.md` 中的 `POST /api/vision/locate` 与 `POST /api/color/analyze`，部署到独立 HTTPS 地址。
2. 后端配置 CORS：允许 `http://localhost:5173` 与 `https://<用户名>.github.io` 的 `POST`（`multipart/form-data`）与 `OPTIONS`。
3. 前端仓库设置变量后重新构建：`VITE_API_MODE=http`、`VITE_API_BASE_URL=<后端地址>`。
4. 密钥只放后端环境变量，前端只存地址。

## 14. 常见故障

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示“摄像头权限被拒绝” | 权限弹窗点了拒绝 | 地址栏锁形图标改回允许，停止后重新开始 |
| 提示“被其他应用占用” | 视频会议等占用摄像头 | 关闭占用应用，重新开始 |
| 一直“正在采集背景” | 画面在动（人或衣物在画面中） | 移出衣物、保持不动；仍失败则点停止再开始 |
| 频繁提示“背景发生明显变化” | 摄像头被碰动或光照剧变 | 固定摄像头、稳定光照，等待重新采集完成 |
| 方向提示与实际相反 | 方向校准未完成/异常 | 停止后重新开始，校准步骤动作幅度稍大一点 |
| 颜色明显不对 | 背景与衣物颜色接近 / 反光 | 换简洁背景、避免强光直射衣物 |
| 没有声音 | 浏览器无中文语音或系统静音 | 页面会提示“未检测到中文语音”；切换到“读屏模式”或检查系统音量 |
| `npm install` 失败 | 网络问题 | 使用镜像：`npm install --registry=https://registry.npmmirror.com` |
